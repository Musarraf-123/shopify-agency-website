# Orange & Co. — Shopify Store Design

A responsive Shopify agency portfolio website with four interactive sample storefront concepts.

For Shopify store design and development, [contact me on Fiverr](https://www.fiverr.com/alam_7979/design-a-professional-shopify-dropshipping-store-and-ecommerce-website).

## Features

- Shopify services, custom-scope packages, project inquiry, and FAQ accordion
- Responsive navigation and desktop/mobile portfolio previews
- Four sample storefront demos with interactive sample carts:
  - Terra Ritual — lifestyle
  - Soft Hour — skincare
  - Field Notes Supply — outdoor
  - Still House — homewares
- Fiverr and WhatsApp contact links
- SEO metadata, social sharing metadata, and favicon

The demo brands, products, and prices are illustrative concepts and are not client work.

## Run locally

No build step or package installation is required. From the project directory, start a static server:

```sh
python3 -m http.server 8000
```

Then open `http://localhost:8000`.
